# Cisco – Reserved IP & Secure Access Platform

## Overview
Led product strategy and execution for Cisco’s Reserved IP capability within Secure Access (SSE), enabling enterprises to maintain consistent outbound identity and enforce security policies across distributed cloud environments.

## Problem
- Enterprises required stable outbound IP identity for allowlisting and compliance  
- Policy enforcement was fragmented across hybrid and cloud environments  
- Existing solutions introduced operational complexity and manual configuration  

## What I Built
- Defined and delivered a cloud-native Reserved IP platform capability within Cisco Secure Access  
- Designed platform architecture including:
  - Identity mapping and policy enforcement layers  
  - Distributed data flows across network, endpoint, and cloud systems  
  - Integration points across security and observability platforms  
- Defined API contracts and system integrations to support scalable deployment across enterprise environments  
- Drove cross-platform alignment across Secure Access, observability, and threat intelligence systems  

## Impact
- Scaled product from < $1M to $4M+ ARR (5x growth)  
- Reduced operational overhead through automation and standardized workflows  
- Improved enterprise adoption across complex, distributed network environments  

## Why It Matters
Demonstrates:
- Platform and distributed system design  
- Enterprise security and identity architecture  
- Data flow ownership across complex systems  
- Ability to scale infrastructure products in regulated environments
