# Cisco – Reserved IP & Secure Access Platform

## Overview
Led product strategy and execution for Cisco’s Reserved IP capability within Secure Access (SSE).

## Problem
- Lack of stable outbound identity
- Fragmented policy enforcement
- High operational overhead

## What I Built
- Cloud-native Reserved IP capability
- Defined platform architecture (identity, policy, data flows)
- Integrated across security ecosystem

## Impact
- Scaled from < $1M to $4M+ ARR
- Reduced operational complexity
- Increased enterprise adoption
